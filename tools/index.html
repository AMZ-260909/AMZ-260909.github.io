How to get a key (about two minutes)
  1. Open GitHub’s new token page (sign in if asked).
  2. Token name: anything, e.g. “chapter tool”. Expiration: the longest option.
  3. Repository access: choose Only select repositories, then pick AMZ-260909.github.io.
  4. Under Permissions, click Add permissions (or open Repository permissions), find Contents and set it to Read and write.
  5. Click Generate token at the bottom, copy the text that starts with github_pat_, paste it below and click Save.
