1 · GitHub 钥匙

已连接：。钥匙只存在这台设备的这个浏览器里。

第一次用要放一把钥匙，以后这台设备的这个浏览器就记住了。

钥匙怎么拿（两分钟）
  1. 打开 GitHub 新建钥匙的页面（要登录）。
  2. Token name 随便写，比如“章节工具”；Expiration 选最长的。
  3. Repository access 选 Only select repositories，再选 AMZ-260909.github.io。
  4. Permissions 里点 Add permissions（或展开 Repository permissions），找到 Contents，改成 Read and write。
  5. 点最下面的 Generate token，复制那串 github_pat_ 开头的字，粘到下面，点保存。
